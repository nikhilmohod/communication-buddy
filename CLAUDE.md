# AI Development Instructions

## Mandatory Development Workflow

Before performing development work, read and follow:

`DEVELOPMENT_WORKFLOW.md`

This workflow is mandatory for all development tasks in this repository.

### Critical Rule

NEVER automatically:

- commit
- push
- merge
- rebase
- reset
- deploy

The developer must manually review all changes in VS Code Source Control.

After implementation, validation, and regression review:

**STOP and wait for explicit developer instruction before any Git or deployment action.**

Do not assume approval from a successful test, completed implementation, or developer request to "implement" a feature.
